Plain-English meanings for words you'll hear. You don't need to memorize these; come back whenever a customer uses one.

| Word | What it means |
|---|---|
| **AI agent / coding agent** | An AI assistant that can read a software project, write code and run commands on a developer's instructions. |
| **Anthropic / OpenAI** | The companies that make Claude (and Claude Code) and ChatGPT (and Codex). |
| **API** | A way for one piece of software to talk to another. "Does it have an API?" means "can our other systems connect to it?" |
| **Audit trail** | A complete record of who did what, and when. Auditors and finance love these. |
| **AWS (Amazon Web Services)** | Amazon's cloud: rented computers and services that companies run their software on. |
| **Budget (in Ork Meter Enterprise)** | A monthly token or dollar allowance for a team, with a status shown at 80% and 100%. It informs; it never blocks. |
| **Cached / non-cached tokens** | Cached tokens are things the AI read recently (cheaper). Non-cached tokens are new reading (more expensive). |
| **Chargeback** | Billing each department for its own share of a shared cost. |
| **CI/CD** | Automated steps that test and ship software updates. Like a closing checklist that runs itself. |
| **Claude Code** | Anthropic's AI coding agent. |
| **Cloud** | Computers in someone else's data center that you rent instead of owning. |
| **Codex** | OpenAI's AI coding agent. |
| **Cost center** | An accounting label for a part of the company that money is assigned to. |
| **CTO** | Chief Technology Officer: the top technical leader. |
| **Dashboard** | A screen of charts and numbers that sums up what's happening. |
| **Design partner** | An early customer who uses a product while it's being built and helps shape it. |
| **DevOps** | The practice of building *and* running software smoothly; the "DevOps" in Enterprise DevOps Solutions. |
| **Developer / engineer** | A person who writes software. |
| **FinOps** | Finance operations for cloud and technology spending: the people who track and manage the bill. |
| **GitHub** | The most popular website where companies store and collaborate on code. |
| **Infrastructure** | The computers, networks and services software runs on. Like the foundation and utilities of a house. |
| **Model (AI model)** | The AI "brain" an agent uses. Different models have different strengths and prices. |
| **Observability** | Being able to see inside running systems through metrics, logs and alerts. |
| **Pilot** | A short, paid trial on the customer's real data before a full agreement. |
| **Plugin** | A small add-on that plugs into another program. Ork Meter installs one into Claude Code and Codex. |
| **Pull request (PR)** | A proposed change to code, waiting for a person to review and approve it. |
| **Seat** | One user's license. "$20 per seat per month" means per developer, per month. |
| **Self-hosted** | The customer runs the software on their own computers or cloud account instead of ours. |
| **SSO (single sign-on)** | Signing in with your company account (Google, Microsoft and others) instead of a separate password. |
| **Terminal** | A text window developers type commands into. Installing Ork Meter is one line typed there. |
| **Token** | The unit AI usage is measured and billed in, roughly a short word of text. |
