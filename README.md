# EDOS Sales Academy

A crash course for new EDOS sales team members, published with GitHub Pages:
**https://edos-business.github.io/edos-sales-academy/**

Written for people who are great with customers but new to software. Every page is
plain Markdown; edit it on GitHub and the site updates in a minute or two.

Everything here is public. Never add prices that aren't on our public websites,
unannounced products, customer names, or anything internal.
